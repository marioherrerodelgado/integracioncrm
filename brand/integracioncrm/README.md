# IntegraciónCRM — Brand Kit

## Tipografía
La imagen conceptual original fue generada visualmente, por lo que no existe una fuente tipográfica exacta asociada al render.
Para convertirla en una identidad reproducible, este kit estandariza:

- **Wordmark:** Inter ExtraBold
- **Texto secundario / tagline:** Inter Medium

El SVG principal lleva el wordmark convertido a contornos, por lo que no depende de tener la fuente instalada.

## Colores
- Azul profundo: `#081426`
- Verde mint: `#2DE6A6`
- Verde de transición: `#0A5F4B`
- Gris suave: `#E9EEF2`
- Blanco: `#FFFFFF`

## Archivos
- `01_logos_svg/`: símbolo, logo horizontal y lockups.
- `02_social/`: avatar 1080×1080 en claro, oscuro y mint.
- `03_favicons/`: SVG, PNG e ICO en tres variantes.
- `04_animation/`: GIF de revelado, SVG animado, MP4 y banner GIF 1120×320.
- `05_preview/`: hoja rápida de visualización.

## Nota sobre el GIF de referencia
El GIF adjunto recibido contiene **un único fotograma** de 1120×320. Por eso el banner de este kit conserva ese fondo oscuro/texturizado como referencia y añade una animación propia de IntegraciónCRM.
